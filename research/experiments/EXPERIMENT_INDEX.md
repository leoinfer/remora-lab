# Experiment queue

The complete recovered queue is represented as cards [`E001`](E001.md) through
[`E096`](E096.md). Each card preserves the source name, dependency state,
protocol or falsifier, and normalized status. `PROPOSED`, `DEFERRED`,
`EXPERIMENTAL`, and `TESTED` are navigation labels, not a common evidence
level.

The source queue is [`COMPLETE_EXPERIMENT_QUEUE.md`](../archival/authoritative/COMPLETE_EXPERIMENT_QUEUE.md).
Run only with explicit model, resource, and provenance review; no model files
or private receipts are included in this repository.
