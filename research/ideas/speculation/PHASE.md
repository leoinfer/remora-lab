# PHASE

**Status:** `PROPOSED`

PHASE treats speculative futures as a prediction/outcome tree rather than a
single fixed-depth guess. A scheduler can then compare branch cost, expected
verification work, and accepted-token value while retaining explicit
rejection paths.

The source description is preserved in the REMORA master prompt and the
formalization queue. Related records are [`F3`](../../theory/checkers/F3-checker.md),
[`F7`](../../theory/checkers/F7-checker.md), and
[`REMORA-Spark`](REMORA-SPARK.md).
