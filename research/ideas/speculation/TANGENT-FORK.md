# Tangent fork speculation

**Status:** `PROPOSED`

Tangent fork speculation explores small, selectively expanded future branches
whose state can be discarded cheaply when the authority path disagrees. The
idea is related to adaptive fork speculation and PHASE, but it has no claim
of equivalence or measured benefit.

This entry is preserved as a registry-level hypothesis. Its safe next step is
a finite branch-DAG replay with explicit memory and verification costs; see
[`F7`](../../theory/checkers/F7-checker.md) and
[`CE-07`](../../falsified/counterexamples/CE-07.md).
