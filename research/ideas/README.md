# Idea cards

This directory contains section-level cards generated from the recovered atlas
and manifest, plus thematic entry points. The cards preserve a stable ID and
source link so ideas can be discussed without rewriting their evidence into a
single undifferentiated narrative.

Public HERMES titles name the underlying mechanism first. When an idea was
developed through an analogy, the card keeps that reasoning trail under
**Original working analogy** and follows it with the measurable **Technical
interpretation**; the title change does not rewrite the mechanism or erase the
analogy.

- [`atlas/`](atlas/) contains H01–H39 and N01–N26;
- [`manifest/`](manifest/) contains M01–M30;
- [`context/`](context/), [`quantization/`](quantization/),
  [`speculation/`](speculation/), [`residency/`](residency/),
  [`kernels/`](kernels/), [`scheduling/`](scheduling/), and
  [`architecture/`](architecture/) contain thematic navigation pages.
