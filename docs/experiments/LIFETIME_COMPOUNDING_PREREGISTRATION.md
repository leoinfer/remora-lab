# LIFETIME-COMPOUNDING-001 preregistration

This document is committed before the main sequential benchmark. It is a
scientific control record, not a claim that the Remora hypothesis is true.

## Question

At the existing v0 parameter scale, does a Remora local plastic path gain an
age-dependent advantage over a conventional Transformer with a matched LoRA
adaptation budget when both receive the same sequence of related and new
tasks?

The primary comparison is Remora local adaptation versus a conventional
Transformer whose attention `qkv` and `out` projections receive LoRA rank 8.
For the default configuration this is exactly 36,864 trainable LoRA
parameters, matching the four Remora plastic islands exactly. The baseline's
frozen base parameters and its LoRA factors are reported separately; this is
not a claim of identical total storage.

## Fixed curriculum

The curriculum is generated by `environments/lifetime_curriculum.py` with
seed 1701 and disjoint operand ranges:

1. T1 parity, compact `x/y/result` interface;
2. T2 parity, natural-language interface;
3. T3 parity, symbolic interface;
4. T4 modulo-three, a genuinely new concept;
5. T5 ordered comparison, another genuinely new concept.

Every stage has primary, shifted, and unseen-template splits. Exact labels
come from the external deterministic oracle and are never inferred from model
outputs. The generated curriculum metadata and split hashes are written into
the result.

## Arms and matched budget

- Remora local plastic adapter with old-task rehearsal;
- Remora local plastic adapter, target-only;
- Transformer LoRA with old-task rehearsal;
- Transformer LoRA, target-only;
- frozen Remora and frozen Transformer controls.

Base training, stage steps, batch size, sequence length, optimizer, tokenizer,
task examples, seeds, and evaluation windows are shared. The baseline LoRA
rank is chosen for exact trainable-parameter equality, and any remaining
total-parameter or runtime mismatch is reported rather than hidden.

## Primary measurements

After every stage: current-task primary/shifted/unseen exact accuracy, all
previous task accuracies, base text/code validation loss, tokens, steps,
wall-time, throughput, peak VRAM, trainable parameters, changed parameters,
rehearsal tokens, and modeled full-forward training FLOPs.

Derived measures include capability gain per new token, wall-second,
trainable parameter, changed parameter, and modeled FLOP; retention and
forward/backward transfer; and steps/tokens/seconds to the predeclared exact
accuracy threshold.

## Predeclared support and falsifiers

Evidence in favor requires all of the following to be measured rather than
assumed: both scratch-trained models learn the base stream; local adaptation
updates stay bounded; the Remora-versus-LoRA difference is evaluated at equal
trainable budget; and shifted/unseen interfaces are included.

The lifetime-compounding hypothesis is weakened if any of these persist after
debugging and a matched rerun:

- LoRA+rehearsal matches or beats Remora retention and forward transfer at the
  same adaptation budget;
- Remora's apparent gain disappears after normalization by wall time or
  modeled full-forward compute;
- later related parity stages do not require fewer examples/steps than T1;
- shifted or unseen interfaces collapse while the same-interface score rises;
- frozen controls match the adapted arms;
- aged Remora surgery later requires broad retraining or causes large global
  regression;
- the common bus ablation is equal or better on transfer and retention;
- duplicate evidence produces the same confidence as independent evidence;
- provenance/manual answers cannot be mechanically checked against the graph.

No result will be promoted to a production architecture from this benchmark.
Scaling remains gated until the adversarial comparison is complete.
