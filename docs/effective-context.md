# Effective context

The effective-context program asks how much useful history can be retained
when device memory, host memory, storage bandwidth, compression error,
retrieval policy, and recovery cost are all counted.

The 10M target is a hypothesis about that effective budget. It is not a claim
that HAR has run dense attention over ten million positions, nor that a single
compressed page representation preserves arbitrary history. A valid future
result must publish the representation, quality metric, attended fraction,
reconstruction path, and failure behavior.
